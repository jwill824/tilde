<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Registry metadata -> Ink browser UI | Static metadata becomes terminal-visible labels and selection values. |
| Browser UI -> package-manager/defaultbrowser utilities | User selections can trigger install/default-browser commands through existing wrappers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02 | Spoofing | Browser labels rendered by `BrowserStep` | mitigate | Consume metadata already validated by Plan 01 and reject malformed/control-character labels in schema or tests; component tests assert expected labels from registry data. |
| T-01-02B | Tampering | `installCask` and `defaultbrowser` arguments | mitigate | BrowserStep maps only validated `install.homebrew.cask` and `externalIds.defaultbrowser` fields; tests mock command utilities and assert exact arguments. |
| T-01-SC | Tampering | package installs | accept | This plan adds no npm/pip/cargo install task; Homebrew behavior remains existing runtime behavior and is mocked in tests. |
</threat_model>
