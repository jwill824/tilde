## Trust Boundaries

|----------|-------------|
| Inventory report -> config-first confirmation | Summary text can influence user trust before applying changes. |
| Inventory report -> wizard summary | Summary text must stay concise and not leak raw local file contents. |
| Startup inventory state -> config-first mode | Config-first must consume existing report data without triggering additional command execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-15 | Spoofing | Config-first and wizard inventory summaries | mitigate | Render evidence counts, Homebrew request-status counts, and warnings only; block final managed/manual/OS-provided labels per D-02. |
| T-02-16 | Information Disclosure | Config-first inventory block | mitigate | Render aggregate counts and known labels only; do not dump rc/env content or unmatched audit names by default. |
| T-02-17 | Denial of Service | `ConfigFirstMode` inventory display | mitigate | Accept report data as a prop and do not run scanner commands from config-first rendering. |

</threat_model>
