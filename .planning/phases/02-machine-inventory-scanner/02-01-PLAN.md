<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External CLI output -> inventory scanner | Homebrew and environment helper output is untrusted machine data parsed into facts. |
| Local filesystem -> inventory scanner | Dotfiles and rc files may contain secret-looking content and must not be resolved or persisted as secrets. |
| Metadata app paths -> inventory scanner | Static metadata paths are checked read-only and become app bundle evidence in the report. |
| Inventory report -> summary helper | Evidence and warnings become user-facing text and must not overclaim final provenance categories. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `src/inventory/scan.ts` Homebrew matching | mitigate | Use `listInstalledFormulae()` and `listInstalledCasks()` helper results as arrays; do not concatenate package names into shell strings. |
| T-02-02 | Information Disclosure | `src/inventory/scan.ts` rc/env capture compatibility | mitigate | Keep rc/gitconfig data inside `environment`, preserve existing secret exclusion behavior, and do not resolve backend secret references. |
| T-02-03 | Spoofing | `src/inventory/summary.ts` labels | mitigate | Render evidence/count labels only; do not emit tilde-managed, manual, OS-provided, or final provenance labels in Phase 2 per D-02. |
| T-02-04 | Denial of Service | `scanInventory()` subsystem failures | mitigate | Catch subsystem failures independently and convert them into `InventoryWarning` data plus unknown states. |
| T-02-04A | Information Disclosure | `scanInventory()` app-path checks | mitigate | Check only metadata-declared `install.appPath` strings with read-only filesystem access and persist only path plus exists boolean evidence. |
| T-02-SC | Tampering | npm installs | accept | No package-manager install tasks exist in this plan; package legitimacy audit in research lists no new packages. |
</threat_model>
