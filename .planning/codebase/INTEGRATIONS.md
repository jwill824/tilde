# External Integrations

**Analysis Date:** 2026-06-12

## APIs and External Services

**Homebrew:**
- Used as the primary macOS package manager.
- Plugin: `src/plugins/first-party/homebrew/index.ts`.
- Commands include `brew --version`, `brew list`, `brew install`, and the Homebrew installer shell script.

**GitHub CLI:**
- Used for account authentication and context switching.
- Plugin: `src/plugins/first-party/gh-cli/index.ts`.
- Commands include `gh auth login`, `gh auth switch`, and `gh auth status`.

**1Password CLI:**
- Used as a secrets backend.
- Plugin: `src/plugins/first-party/onepassword/index.ts`.
- Commands include `op --version` and `op account list --format=json`.
- Runtime shell init emits `eval "$(op signin)"`.

**vfox:**
- Used for language version management.
- Plugin: `src/plugins/first-party/vfox/index.ts`.
- Commands include `vfox install`, `vfox use --global`, and `vfox list`.

**direnv:**
- Used to load per-context environment.
- Plugin: `src/plugins/first-party/direnv/index.ts`.
- Generates `.envrc` shell content with git identity and backend secret references.

**defaultbrowser:**
- Used to set the macOS default browser.
- Implemented in `src/plugins/first-party/browser/index.ts` and `src/steps/browser.tsx`.
- Requires Homebrew formula `defaultbrowser` and triggers a macOS system confirmation dialog.

## Data Storage

**Local Files:**
- User config is read from explicit path, working directory, git root, or `~/.tilde/tilde.config.json`.
- Config discovery lives in `src/utils/config-discovery.ts`.
- Config writes use atomic temp-file rename in `src/config/writer.ts`.

**Dotfiles Repository:**
- Managed dotfiles are written under the configured `dotfilesRepo`.
- Writer entry point is `src/dotfiles/writer.ts`.
- Generated files include git config and shell profile files.

**Wizard Checkpoints:**
- Checkpoint state is managed by `src/state/checkpoint.ts`.
- The wizard saves progress during `src/modes/wizard.tsx` navigation.

## Authentication and Identity

**Git Identity:**
- Config schema models per-context git name/email in `src/config/schema.ts`.
- Gitconfig generation lives in `src/dotfiles/gitconfig.ts`.
- GitHub context switching is generated by the gh-cli account connector.

**Account Connectors:**
- `gh-cli`, `https`, and `ssh` connector plugins implement GitHub auth approaches.
- API contract is in `src/plugins/api.ts`.

## Monitoring and Observability

**Logs:**
- The app relies on terminal stdout/stderr and Ink UI output.
- `src/utils/exec.ts` wraps command failures in `PluginError`.
- No external error tracking or analytics service is integrated.

## CI/CD and Deployment

**CI Pipeline:**
- GitHub Actions CI in `.github/workflows/ci.yml`.
- Runs lint, build, config doc validation, unit tests, contract tests, and integration tests.
- CI ignores pushes that only touch `specs/**`, `terraform/**`, Markdown, or `.specify/**`.

**Release Pipeline:**
- Semantic Release runs from `.github/workflows/release.yml` on `main` changes to source, tests, package files, or release config.
- Uses `GH_TOKEN` for repository and npm publishing permissions.

**Static Site:**
- Static install page lives in `site/tilde/`.
- Docs site assets also exist under `site/docs/`, with build output ignored.
- Deploy workflow is `.github/workflows/deploy-site.yml`.

## Environment Configuration

**Development:**
- No `.env` is required for core tests.
- `.env` and `.env.*` are ignored by `.gitignore`.
- Test suites mock `execa` and `src/utils/exec.ts` for external command boundaries.

**Production:**
- Runtime is the end user's macOS machine.
- External CLIs and applications are installed or detected on that machine.

## Webhooks and Callbacks

- None detected. This is a local CLI with no inbound HTTP server.
